# Say What Actually Broke

One single line of software error copy that tells the user the brutal truth about what went wrong — and makes them laugh on the way. Entry for the make.fun bounty: https://make.fun/bounty/u-po-pu-say-what-actually-broke-a2c153b5

Run `python3 main.py` and it writes the line to `entry.txt` in `MAKEFUN_OUTPUT_DIR` (or `/output`).
